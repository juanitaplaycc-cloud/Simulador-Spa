Como usar el simulador

  1. Abre la consola del navegador (F12 o Option+Cmd+C en Safari) para ver el detalle de cada operacion.
  2. Elige una accion en la barra lateral. Las que piden datos abren una ventana emergente.
  3. Reserva servicios con su boton en ela tarjeta o con la accion Reservar un servicio.
  4. Revisa el resumen: con 3 o mas servicios se aplica el descuento de paquete.
